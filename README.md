# 乐不学

Windows 课程看板，支持课程动态、作业截止提醒、每周课程表和本地自定义任务。

本仓库用于发布软件与记录更新。[下载乐不学.exe](https://github.com/cicfish/le-bu-xue/raw/refs/heads/main/%E4%B9%90%E4%B8%8D%E5%AD%A6.exe)。更新时从托盘退出旧版，再替换 EXE；本地课程缓存、登录会话、设置和自定义任务保存在独立目录。

软件当前不提供在线自动更新。每次启动自动同步一次学校数据，此后可点击“立即同步”手动同步。

## 更新日志

以下按功能迭代顺序记录。早期构建未使用正式版本号，不补记未经确认的发布日期。

- 将学期名称规范为“2026-2027 秋季学期”等格式。
- 修复筛选和字体菜单展开后立即收起的问题。

#### 课程动态与附件

- 支持点击动态主体展开作业要求、资料说明和附件列表。
- 保留右侧箭头，支持跳转学校平台原页面。
- 显示附件名称、格式和文件大小，提供下载入口。
- 调整资料分组标题背景与附件框间距。

#### 课表与日程

- 增加新版延河课堂每周课表，显示课程名、校区、教室和回放状态。
- 支持点击“有回放”打开对应课程回放。
- 增加第 1 至第 13 节标准上课时间轴，课程块按时间排列。
- 调整课程块配色，校区与教室信息分行显示。
- 补充课表登录会话获取流程，同步失败时保留已有课表。
- 月历显示未确认已提交的截止事项，右侧当日任务列表支持独立滚动。

#### 自定义任务与设置

- 支持新建、编辑、完成和删除本地自定义任务。
- 支持填写标题、说明、截止时间并添加附件。
- 增加开机启动、后台运行、悬浮条和中英文字体设置。
- 增加内置只读使用说明，并打包说明中的示例图片。

#### 桌面悬浮条与运行资源

- 支持拖动悬浮条、打开看板及查看待提交和即将截止数量。
- 调整窗口层级，在全屏游戏或视频场景下隐藏悬浮条。
- 修复不同 DPI 下文字截断、边缘重叠、圆角突变和文字模糊问题。
- 缩减悬浮条右侧空白，调整图标与文字比例。
- 关闭主窗口后释放浏览界面资源，同步结束后释放浏览器驱动。
- 取消定时自动同步，保留每次启动时的一次同步。

#### 打包与本地数据

- 改为单个 EXE 分发，内置界面、后台、字体和使用说明。
- 课程缓存、登录会话和自定义任务分别保存在用户本地目录。
- 分发文件不包含用户的学校账号、登录 Cookie 或课程缓存。
