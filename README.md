# 乐不学

Windows 课程看板，支持课程动态、作业截止提醒、每周课程表和本地自定义任务。

本仓库用于发布软件与记录更新。[下载乐不学.exe](https://github.com/cicfish/le-bu-xue/raw/refs/heads/main/%E4%B9%90%E4%B8%8D%E5%AD%A6.exe)。更新时从托盘退出旧版，再替换 EXE；本地课程缓存、登录会话、设置和自定义任务保存在独立目录。

当前采用手动下载并替换 EXE 的方式升级，版本通知暂未启用。每次启动自动同步一次学校数据，此后可点击“立即同步”手动同步。

## 使用说明

##### 2026.10.16 改动建议可提交至 3465535416@qq.com
首次使用时，点击总览部分<img src="guide-assets/Pasted%20image%2020261015224913.png" width="89" alt="使用说明示例">跳转校统一认证进行新版延河课堂登录；点击<img src="guide-assets/Pasted%20image%2020261015225002.png" width="93" alt="使用说明示例">进行实时同步；未同步时使用上次保存的数据

---
### 总览

课程表：
- 学校课表时间、教室；点击“有回放”可打开回放；
- 教学中心提供本学期完整课表；延河回放用于补充最近周的回放入口
- 示例<img src="guide-assets/Pasted%20image%2020261015225424.png" width="81" alt="使用说明示例">

日程表：
- 有截止日期且未显示为已提交的事项会标在日历上
- 示例![使用说明示例](guide-assets/Pasted%20image%2020261015225734.png)

全部动态：显示所有的课程内容，包括作业、实验、课件、资料
- 点击内容，显示内容说明和附件，提供下载功能
- 右侧箭头跳转到延河课堂原界面
- 示例![使用说明示例](guide-assets/Pasted%20image%2020261015225952.png)
---
### 即将截止

- 7 天内未确认已提交的事项
- 自定义todo list，用于临时ddl，可自行添加或删除![使用说明示例](guide-assets/Pasted%20image%2020261015234311.png)
---
### 待提交

- 所有未提交部分
---
### 考试

- 教学中心发布的考试安排；显示日期、时间、教室、座位和监考信息，未公布项保留为待定
---
### 资料

- 课程中的课件、实验资料等，按照课程分类
---
### 设置

- 开机启动；后台运行
- 桌面悬浮条（用于提醒），占用内存极低
- 界面中英文字体设置
